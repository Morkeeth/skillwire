Supplementary guidance for implementation, from the current Modern Web Guidance Dialog and Light-Dismiss a Dialog references. Prefer native dialog opened with showModal. Label the dialog via its title and place initial focus purposefully. Give a visible dismiss button. Use closedby="any" for native pointer light dismissal. Detect missing closedBy on HTMLDialogElement.prototype before installing fallback listeners. On fallback, compare both pointer-down and pointer-up coordinates to the dialog bounding rectangle, so that content padding or a drag originating inside does not close it. Use the browser's default Esc and focus handling with a native dialog. Scope display styles to the open state so CSS cannot reveal a closed dialog. Use cancellation/close events if completion logic is required. Preserve existing form controls outside the dialog.
