Install into a fresh project
  1. Unzip the download into a temporary folder. Read SKILL-SOURCES.json, every warning line, the pinned repository licence and any skill-specific terms.
  2. For Codex, create .agents/skills/ inside your project. Copy each reviewed skill folder there, keeping its SKILL.md and supporting files together. Use the skill name as its folder name. Do not replace an existing skill without comparing it.
  3. Start a fresh Codex session in that project and confirm the skill appears. Ask for it by name. Discovery does not prove the full instructions were read or that the skill improves results.

Downloaded scripts may run with your agent’s permissions if you later use them. Start in a disposable project with no private files or credentials. Other harnesses use different install locations; follow their official instructions.

Earlier studies, limits and detailed methods

Historical setup

Use your existing Codex or Claude Code subscription and a selected installed skill or public stack. Freeze the task and independent outcome checks, then compare the same starting files with and without those instructions. No extra API key or hosted evaluation service.

Set up a local evaluation Download CLI tools and example

Local detection does not start calls. Explicit trials use your chosen provider and subscription allowance. Unknown/API-key authentication is refused. Local trial setup freezes settings and disables unrelated customizations to keep the comparison controlled.

Judge the outputs yourself

Automated checks can miss usefulness, clarity and mistakes that matter to you. Make a blind A/B choice from the saved files before seeing which condition produced them. Ties and “cannot judge” are valid outcomes.

Review a blind pair

First native TDD family: grader contract under review

Ten matched pairs completed with a pinned public TDD skill folder. Recorded task passes were 8 of 10 with it installed and 7 of 10 without. The skill body was seen in one treatment tool trace; nine reads were unobserved, and internal use is unknown. A frozen reference accepted ASCII DEL where the task said to reject it, so the first family is disputed. A new ten-case contract is sealed for review with no model runs. These counts are not a skill benefit claim. Blind human choices have not been collected.

Earlier Skill Issue benchmark

The August SkillsBench entry reported that the skill body opened on only 3 of 8 panel tasks. Its treated versus baseline solve rates showed no detectable lift, and the reported effect was within its A/A noise. Raw rollouts were later deleted, so those figures cannot be rechecked from the repository. The current SkillWire pilot is a separate native Codex task with an 8/8 tie. Do not combine their counts or infer a general result.
